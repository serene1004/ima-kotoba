# いまことば (Ima Kotoba)

> 지금의 마음을 일본어로 기록해요.

짧은 일본어 한두 문장으로 그 순간의 감정과 생각을 남기는 개인 기록 서비스입니다. 긴 일기 대신, 생각나는 순간 가볍게 한마디를 남기고 하루의 흐름을 돌아보는 데 초점을 둡니다.

## 현재 구현 상태

UI 프로토타입 단계입니다. 화면의 기록 데이터는 하드코딩된 샘플이며, 새로 작성한 기록은 현재 세션에서만 임시로 반영됩니다.

- 반응형 웹 대시보드와 내부 스크롤 레이아웃
- 오늘의 기록 카드와 감정 선택, 실제 당일 기록 수 표시
- 일본어 문장·선택 한국어 의미 작성 UI
- 작성 후 홈에 즉시 반영되는 더미 기록
- 내 정보 화면의 지난 기록 UI (당일 작성 기록 즉시 반영)
- 인증 기반 로그인 화면 UI (인증 미연동)
- 연보라 브랜드 로고·파비콘
- 라우트: `/`, `/write`, `/profile`, `/login`

## 기술 구성

- React + TypeScript + Vite
- React Router
- pnpm
- ESLint (Airbnb 기반)
- Vercel SPA rewrite: `vercel.json`

## 실행

```bash
pnpm install
pnpm dev
```

개발 서버는 `http://localhost:9050`에서 실행됩니다.

```bash
pnpm run lint
pnpm run build
```
